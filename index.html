Deskripsi Lengkap

Caffe Adin adalah sistem pemesanan restoran digital yang memungkinkan pelanggan memesan makanan secara mandiri melalui scan QR Code di meja. Dilengkapi dashboard admin untuk manajemen menu, pemantauan pesanan real-time, serta analisis penjualan berbasis grafik.

💡 Pengembangan:
Project ini dikembangkan dengan memanfaatkan AI (ChatGPT/GitHub Copilot) sebagai asisten pemrograman. Saya bertanggung jawab penuh atas arsitektur sistem, desain database, integrasi fitur, pengujian, dan deployment. AI digunakan sebagai alat bantu untuk mempercepat proses pengembangan dan learning.

⚡ Fitur Unggulan:
QR Code per meja (8 meja) · Pemesanan mandiri via HP · Dashboard admin dengan grafik penjualan · Manajemen menu (CRUD + upload gambar) · Export laporan Excel/CSV · Filter pesanan by tanggal · Pencarian menu · Cetak invoice/struk · Login admin · Responsive design

🛠️ Teknologi:
Backend: PHP 8.2, MySQL · Frontend: Tailwind CSS, JavaScript · Library: Chart.js, QRCode.js, Font Awesome · AI Tools: ChatGPT (coding assistant), GitHub Copilot
